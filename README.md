# Aura Client

Personal launcher and client mod for Minecraft Java Edition
(Forge 1.8.9, Fabric 1.21.11 and 26.2).

## What the launcher does
- Signs in with the player's own Microsoft account using the official
  Microsoft device-code login, then Xbox Live and Minecraft services.
- Downloads the official game files from Mojang and starts the game.
- Never stores or shares passwords; only the session tokens needed to play,
  saved locally on the user's PC.

## Status
Private use only, not distributed.
